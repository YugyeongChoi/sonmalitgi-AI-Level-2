# 중급 공식 v4 모델 연결

SOURCE.json에 고정한 공식 저장소 v4_11words 가중치를 재학습 없이 사용한다. 상체 12점·양손 42점을 194개 특징으로 변환하여 32타임스텝으로 리샘플링한다. 입력 스키마는 mediapipe-body-hands-v1(포즈 33점 + 양손 각 21점). 목·어깨 정규화가 필요하므로 포즈가 없는 프레임은 모델에 넣지 않고 상체 안내를 반환한다.

원본 서버 ai_server/ml/word_dataset.py, ai_server/ml/word_model.py, landmarks.py, segmenter.py를 고정된 버전에서 가져왔으며 패키지 상대 import만 수정했다. adapter.py는 기존 웹 WebSocket 프로토콜로 연결한다. classes.json의 11개 단어를 지원한다. hands 세그먼터와 원본 특징 계산을 유지한다. 재학습·최종 테스트는 수행하지 않았다.

운영은 Railway 무료 플랜 서비스 생성 제한으로 기존 AI 서버 안에 중급과 고급을 각각 로드한다. 중급 WORD 요청과 사전 intermediate 범위만 이 모델을 사용한다. 고급 unit5 체크포인트·입력·판정은 유지한다. 서버는 영상 대신 포즈·손 좌표만 수신하며 좌표를 디스크에 저장하지 않는다.

웹캠의 양손만 검출하던 과거 운영 모델과 달리 중급 화면에서는 Worker에 Pose Landmarker Lite를 추가한다. 고급 화면은 손 검출만 유지한다. 기존 중급 평가 정책(점수 0.5), 사전 후보 정책(0.8, 2회 연속)을 유지하며 점수를 보정 정확도로 해석하지 않는다. 사전의 짧은 창 인식은 원본 전체 단어 분류와 다르므로 실제 사용자 정확도는 별도 검증이 필요하다.

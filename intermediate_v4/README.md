# 중급 공식 v4 모델 연결

SOURCE.json에 고정한 공식 저장소 v4_11words 가중치를 재학습 없이 사용한다. 상체 12점·양손 42점을 194개 특징으로 변환하여 32타임스텝으로 리샘플링한다. 입력 스키마는 mediapipe-body-hands-v1(포즈 33점 + 양손 각 21점). 목·어깨 정규화가 필요하므로 포즈가 없는 프레임은 모델에 넣지 않고 상체 안내를 반환한다.

원본 서버 ai_server/ml/word_dataset.py, ai_server/ml/word_model.py, landmarks.py, segmenter.py를 고정된 버전에서 가져왔으며 패키지 상대 import만 수정했다. adapter.py는 기존 웹 WebSocket 프로토콜로 연결한다. classes.json의 11개 단어를 지원한다. hands 세그먼터와 원본 특징 계산을 유지한다. 재학습·최종 테스트는 수행하지 않았다.

운영은 Railway 무료 플랜 서비스 생성 제한으로 기존 AI 서버 안에 중급과 고급을 각각 로드한다. 중급 WORD 요청과 사전 intermediate 범위만 이 모델을 사용한다. 고급 unit5 체크포인트·입력·판정은 유지한다. 서버는 영상 대신 포즈·손 좌표만 수신하며 좌표를 디스크에 저장하지 않는다.

웹캠의 양손만 검출하던 과거 운영 모델과 달리 중급 화면에서는 Worker에 Pose Landmarker Lite를 추가한다. 고급 화면은 손 검출만 유지한다. 중급 평가는 점수 0.5 이상 정답을 새 좌표 구간마다 누적 2회 확인한다. 중간 오인식·미검출에도 누적은 유지하고 평가를 새로 시작하면 초기화한다. 적립 후 입력 창을 비워 같은 겹친 창으로 중복 적립하지 않는다. 사전 후보 정책(0.8, 2회 연속)은 유지하며 점수를 보정 정확도로 해석하지 않는다. 사전의 짧은 창 인식은 원본 전체 단어 분류와 다르므로 실제 사용자 정확도는 별도 검증이 필요하다.

## 반복 수행 구분

정답을 한 번 인정하면 적립을 잠근다. 모델이 같은 정답을 계속 예측해도 추가 적립하지 않는다. 포즈의 양 어깨가 신뢰도 0.5 이상으로 보이고 양손목이 어깨 중점보다 어깨너비의 0.55 이상 아래에 있는 자세가 600ms 지속돼야 잠금을 해제한다. 손 좌표가 검출되면 손목이 같은 경계 아래인지도 확인한다. 300ms 초과 수신 공백이나 포즈 미검출은 종료로 인정하지 않는다. 잠금 해제 시 분석 창을 비워 대기 자세가 다음 동작에 섞이지 않게 한다. 누적은 유지하며 중급 촬영 제한은 20초다. 이는 명시적 대기 자세로 반복 수행을 구분하는 방식이며 임의 동작의 의미적 종료를 자동 분할하는 모델은 아니다. 고급과 사전 정책은 유지한다.

양손목 위치는 검출된 손의 0번 점을 우선 사용하고, 손이 없으면 포즈 손목 신뢰도 0.5 이상일 때만 대체한다. 자동 해제가 안 되면 웹의 ‘다음 동작 시작’이 next_repetition 메시지를 전송한다. 서버는 적립이 잠긴 중급 회차에서만 준비를 해제하고 분석 창을 비우며, 이 메시지 자체로는 점수를 올리지 않는다.

## 설문 정리용 최종 결과

현재 중급 기준은 20초 내 분리된 정답 수행 2회다. 2회 인정 즉시 PASS로 종료하고, 제한 시간 또는 사용자의 평가 종료 시 2회 미달이면 FAIL로 종료한다. 중간 RETRY와 최종 FAIL을 구분한다. 최종 결과에 success_count/required, evaluation_seconds, termination_reason(passed/time_limit/user_end), finished_at(UTC), evaluation_policy를 포함한다. 웹에서 표현·결과·횟수·소요 시간·종료 사유를 표시하고 단일 시도 CSV를 다운로드할 수 있다. CSV는 사용자 직접 저장이며 원본 영상·좌표는 포함하지 않는다. 모델 판정 결과는 실제 수어 정확도의 정답 라벨과 구분해 해석한다. 고급·사전 조건은 변경하지 않는다.

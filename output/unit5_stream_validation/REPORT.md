# 유닛 5 실시간 판정 검증 실험

## 평가 범위

2026년 11월 18일 기준 운영 배포용 문장 모델과 단어 모델을 로컬에서 불러와 검증했다. 문장 모델은 REAL01~REAL12, 단어 모델은 REAL01~REAL10으로 학습한 버전이다.

검증 대상은 REAL13·REAL17의 문장 5개 × 촬영 각도 5개 × 사이너 2명으로 총 50개 클립이다. 각 클립을 정답 목표 1개와 다른 목표 4개에 각각 입력했다. 실험마다 정답 시도 50회와 오답 시도 200회다. REAL14·REAL15·REAL16·REAL18의 최종 테스트 클립은 읽거나 평가하지 않았다.

## 재현 방법과 가정

- 운영의 HandsWordAdapter, WordSequence, Evaluator를 그대로 불러왔다. 최신 프레임을 유지하는 버퍼와 2프레임 판정 간격, 첫 단어 확인 후 최근 2프레임을 남기는 처리 및 종료 시 남은 프레임의 마지막 판정을 재현했다.
- 현재 단어 판정은 첫 단어 최근 8프레임, 두 번째 단어 최대 12프레임을 사용한다. 문장 판정은 16프레임부터 시작해 최대 32프레임을 사용한다. 점수 기준은 0.90, 연속 판정은 2회다.
- 추출된 키포인트에는 원본 영상 타임스탬프와 fps가 없어 원본 30fps를 가정하고 8·6·4fps로 샘플링했다. 실제 원본 fps 확인 후 시간 관련 수치를 재검산해야 한다.
- 좌표는 가로·세로에 동일한 척도를 적용해 브라우저 입력 형식으로 변환했다. 원본 키포인트의 해부학적 왼손·오른손을 유지했다. 실제 웹캠의 MediaPipe 재추출, 가림, 누락, 네트워크 왕복, 브라우저 처리 시간은 재현하지 않았다.
- 모델 입력은 기존 코드에서 32타임스텝으로 리샘플링된다.
- 통과 시간은 가정한 원본 클립 시작부터 최초 PASS 판정 프레임까지의 영상 시간이다. 서버 응답 지연이나 동작 종료 후 대기 시간은 포함하지 않는다.
- 정답 통과율은 목표 문장과 일치하는 시도의 PASS 비율이고, 오통과율은 다른 문장을 입력한 시도의 PASS 비율이다. 문장 전체 분류 정확도와 별도 지표다.

| 입력 클립 | 설정한 목표 | 결과 |

| 시간/급하다 · REAL17 · 오른쪽(R) | 약속/늦다 | 2.13초에 오통과 |

## 실험에서 확인한 점

1. 현재 설정의 실시간 모의 정답 통과율은 98%였다. 앞서 문장 전체 입력으로 얻은 검증 정확도 100%와 평가 방식이 다르다.
2. 점수 기준을 0.80으로 낮춰도 이번 클립에서 정답 통과 수와 오통과 수가 바뀌지 않았다. 이 실험에서는 기준을 낮출 이득이 확인되지 않았다.
3. 두 번째 단어 구간을 16프레임으로 늘리면 오통과 1건이 줄었지만 2건은 남았다. 연속 판정을 3회로 늘려도 같은 오통과 2건이 남았고 통과 시간 중앙값은 0.23초 늘었다.
4. 4fps에서는 운전/빨리의 정답 통과가 0/10이었다. 프레임 수로 고정한 판정 구간이 낮은 수신 속도에서는 긴 시간의 움직임을 담게 되므로 실제 웹캠 수신 fps 측정과 시간 기준 구간의 추가 검증이 필요하다.
5. 정면 클립 10개는 8fps와 6fps에서 모두 통과했다. 실제 사용자의 웹캠 인식 성능을 입증하기에는 사람 수와 입력 조건이 제한적이다.

## 다음 확인 및 운영 반영 상태

이번 작업으로 운영 판정 기준을 변경하거나 배포하지 않았다. 오통과가 남아 있으므로 이 결과만으로 최종 기준을 확정하지 않았다.

실제 웹캠에서 수신 fps·판정 구간 시간·예측 단어를 측정하는 단계가 남아 있다. 화면 좌우 손 구분은 사용자가 정상 동작을 확인했지만, 웹캠 입력으로 정답 및 다른 문장 시도를 수집한 평가는 아직이다. 손 정지·무관한 동작·다른 문장 전체에 대한 오통과 평가도 추가로 필요하다.
